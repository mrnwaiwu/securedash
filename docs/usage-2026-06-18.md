# SecureDash Usage Notes — 2026-06-18

Quick reference for running and reading the dashboard.

## Running locally

1. Install dependencies: `pip install -r requirements.txt`
2. Start the app: `python app.py`
3. Open `http://localhost:5000` in a browser.

## Reading the panels

- **Findings by severity** — stacked counts; the red segment is the one to
  watch day to day.
- **Open vs. resolved** — a widening gap means triage is falling behind
  intake.
- **Top sources** — which scanners or feeds produce the most findings, useful
  for spotting a noisy integration.

## Tips

- Use the date filter to scope to a single sprint before a review meeting.
- Export the current view to CSV when you need to share numbers outside the
  app.
