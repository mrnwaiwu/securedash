# securedash

A full-stack Flask security dashboard that displays open findings, severity counts, and real-time alerts.

## Setup
```bash
pip install flask
python app.py
# Open http://localhost:5000
```

## Features
- Summary cards (Critical / High / Medium / Low)
- Open findings table with severity badges
- Recent alerts feed
- REST API: `/api/findings`, `/api/summary`

## Tech Stack
Python · Flask · HTML/CSS · Jinja2
